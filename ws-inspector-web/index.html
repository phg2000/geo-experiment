Web-Search Raw Run Inspector

One query → the raw anatomy of a ChatGPT web-search run: queries, answer, citations (ground truth), the runtime consideration set, and the model's self-report (unverified). Set Runs > 1 to repeat the same query and see how much the searches and sources vary.

Geo-targets the web search (any mode) and is named in the ChatGPT-like prompt. Cities from Open-Meteo's geocoding API.

Heads up: runs execute in OpenAI background mode (a few minutes each) and run in parallel, so N runs take about as long as one. Keep this tab open while it polls. Each run is a billable OpenAI call.
